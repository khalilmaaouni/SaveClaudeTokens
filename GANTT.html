Risk management, insights and alerts

Alert: both frameworks kept

superpowers and ultrapowers inject overlapping manifestos at every session start. You chose to keep both, which is a deliberate cost, not an oversight. What to do: if a session ever feels slow to start, revisit this first, since it is the single largest remaining always-on block after CLAUDE.md.

Risk: usage zeros are soft evidence

The transcript scan proves a plugin was never invoked by name, but two plugins register under a hashed prefix, so their zeros are unreliable. What to do: treat zeros as a shortlist to review, never as an automatic delete, and keep every disable reversible.

Insight: the audit is repeatable

The scan script and the per-plugin token query are both one-liners in the skill. What to do: re-run them monthly, before adding any new plugin, so the startup weight never drifts back up unnoticed.

Watch: ponytail is third-party

Version 4.9.0 ships three hooks that run outside model context. Network calls exist only in its tests and benchmark scripts, not in the hooks. What to do: re-check that on any version bump, since a hook is code that runs on your machine at every session start.

Install ponytail

Audit inline, not by subagent

The 90-day transcript scan ran as one python script rather than a dispatched agent: it is deterministic, so an agent would have added cost and no judgment. Recorded because choosing not to delegate is itself a decision.
