# Token Shield 1.8.0 release notes (draft for the founder's edit)

Token Shield 1.8.0 is the diagnosis release: the tool now measures YOUR pressure signals, ranks every treatment for a problem against them, and tells you in plain words what to do, why, and how to undo it.

The release also carries our proof story working in public: our first closed experiment returned NOT_PROVEN, and we shipped that verdict instead of a number. A tool that counts other people's waste has to start by refusing to inflate its own. The successor experiment is running with a clean window.

Highlights: transcript pressure signals (MEASURED, with NO DATA where the data is absent), the treatment tournament with one winner and visible losers, intent modes (conservative, balanced, aggressive), guided install and rollback recipes from the curated registry only, advice cards that surface their own stale facts, a ten second dashboard top strip, and HISTORICAL marking for evidence the environment has moved under.

Free, open source, local-first, zero hooks by default. Install:
/plugin marketplace add khalilmaaouni/token-shield
/plugin install token-shield@token-shield
