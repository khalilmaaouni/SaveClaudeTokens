Date: 2026-08-13. Method: web research over the caveman plugin's public footprint (Hacker News thread 47954745, the JuliusBrussee/caveman issue tracker, the andrew.ooo measured review, thenewstack, decrypt, yahoo tech coverage) plus adjacent tools. ## The five personas

1. The skeptic (senior engineer, HN commenter). Wants controlled benchmarks with exact-answer checks; treats unverifiable percentage claims as a mark against the whole tool ("I treat it as a criterion for people who shouldn't be taken seriously", HN). Trust trigger: a benchmark they can run themselves. Distrust trigger: viral framing, meme numbers. TOKEN SHIELD ANSWER: the bench/ reproducible benchmark kit (built 2026-08-13), the claims register, the scorecard's evidence-or-nothing rule.

2. The heavy daily user hitting limits. Wants sessions to last longer; the felt win is "credits lasted 3x longer" (relayed, single-sourced). Their deepest fear is quality loss: reasoning gaps ("Not having that final reasoning laid out... leaves a huge gap", HN) and dumbed-down interaction. TOKEN SHIELD ANSWER: quality preservation as a stance (do-nothing is a valid recommendation, no output-mangling by default), measured not promised; the habits view when it ships.

3. The pragmatic reviewer. Benchmarks before recommending; separates input from output share; found caveman's real savings 30 to 50 percent on output, not the 75 headline, and that a one-line brevity instruction captures most of it (andrew.ooo). Trust trigger: decomposed numbers. TOKEN SHIELD ANSWER: the meter's per-type decomposition, the strategies register now noting where a trivial baseline captures most of a treatment's value (trust sweep, 2026-08-13).

4. The bill-watcher (team or API user). Verbosity is a financial line item; wants dollar-denominated, reproducible proof (relayed via decrypt/pcworld coverage, no individually quoted developer). TOKEN SHIELD ANSWER: dated per-model USD snapshot, API-equivalent wording, the monthly report.

5. The vibe hobbyist. Keeps a tool because it is funny ("Caveman made me laugh", HN). DECISION: out of scope; personality features conflict with the ratified passed-on list (growth and marketing, not code). Parking lot, revisit only on founder direction.
